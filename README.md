## 🚀 Soluções que já implementei

### 01. Onboarding de clientes automatizado

Automatizei a geração de checklists de onboarding de acordo com o tipo de serviço, eliminando sua montagem manual e conectando o **n8n** ao **ClickUp**.

**Tecnologias:** n8n · ClickUp · Workflows · Webhooks

### 02. RPA para migração de dados do eSocial

Desenvolvi automações para extrair e preparar dados do **eSocial** em planilhas, apoiando a migração para o **Alterdata**.

**Tecnologias:** Python · Playwright · OpenPyXL · JSON · Excel

### 03. Integração de processos entre 4 áreas

Padronizei fluxos de **Comercial, Onboarding, Serviços Contábeis e Financeiro** em um workspace, criando maior integração entre equipes e processos.

**Tecnologias:** ClickUp · n8n · APIs REST · Google Sheets · Gmail API

### 04. Automações financeiras e relatórios

Criei integrações para rotinas financeiras, comunicação com clientes e coleta automatizada de relatórios de tráfego pago.

**Tecnologias:** n8n · Asaas API · Meta API · Webhooks
